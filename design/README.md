# OCSO Design Mockups

This folder contains the high-fidelity UI mockups for OCSO.

## Primary screens

1. **01 Conversation workspace.dc.html** — CS Exec conversation workspace, inbox, AI/human control states, customer context and approved tools.
2. **02 Agent overview.dc.html** — CS Lead virtual-agent overview and business performance surface.
3. **03 System control center.dc.html** — Platform Tech Admin infrastructure, worker and telemetry control center.
4. **04 Connections and models.dc.html** — model providers, logical model profiles, MCP connections and technical configuration.
5. **05 Internal agent.dc.html** — OCSO's built-in internal operating agent.
6. **06 Home.dc.html** — role-aware product home/dashboard.

Supporting navigation, index, runtime helpers and shared styles are included alongside the mockups.

These mockups define the visual language for the rest of the product. New screens should extend this system rather than inventing an unrelated design language.

The design source package also contained screenshot/check assets used during design review. The canonical implementation references are the HTML/CSS/JS source files committed here.
